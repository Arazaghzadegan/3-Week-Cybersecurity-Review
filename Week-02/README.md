
# Week 02 – Linux & Cybersecurity Fundamentals

This week focuses on Linux administration, Linux security, system fundamentals, and core cybersecurity concepts.

The material combines theoretical knowledge with practical command-line exercises and security-related tasks.

## Topics Covered

* Linux Fundamentals
* Users and Groups
* File and Directory Permissions
* Ownership and Access Control
* ACLs
* Bash and Shell Fundamentals
* Shell Scripting
* Linux Commands
* System Logs
* `journalctl`
* TTY and Terminal Concepts
* Remote Access Concepts
* Cybersecurity Fundamentals
* Risk Concepts
* Threats and Vulnerabilities
* SLE / ARO / ALE
* Practical Security Exercises

## Objectives

The main objectives of this week were to:

* Strengthen Linux administration skills
* Understand Linux permissions and access control
* Practice working with users and groups
* Improve command-line skills
* Develop basic Bash scripting skills
* Understand Linux logging and system monitoring
* Review fundamental cybersecurity concepts
* Apply security concepts through practical exercises
