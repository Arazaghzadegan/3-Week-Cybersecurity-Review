## 🎯 Goals

The main goals of this three-week review are:

* Reinforce CCNA knowledge
* Improve Linux administration skills
* Review cybersecurity fundamentals
* Practice security concepts through hands-on exercises
* Improve troubleshooting and problem-solving skills

## 🔄 Review Method

The review follows a cumulative learning approach.

Each study session includes:

1. Learning or reviewing the current topic
2. Reviewing recently studied topics
3. Revisiting older concepts
4. Practicing through exercises and technical questions
5. Connecting concepts between networking, Linux, and cybersecurity

This approach is intended to improve long-term retention rather than relying only on short-term memorization.
