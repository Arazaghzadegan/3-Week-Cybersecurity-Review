# Week 01 – CCNA & Networking Review

This week focuses on reviewing core networking concepts and strengthening my CCNA knowledge through theoretical review, problem-solving, and practical exercises.

## Topics Covered

* Network Fundamentals
* OSI and TCP/IP Models
* Ethernet and Network Communication
* Switching Fundamentals
* VLANs
* IP Addressing
* Subnetting
* STP / RSTP
* EtherChannel
* Routing Fundamentals
* Network Troubleshooting

## Objectives

The main objectives of this week were to:

* Strengthen networking fundamentals
* Review important CCNA concepts
* Improve subnetting and IP addressing skills
* Understand switching and VLAN operation
* Review Layer 2 protocols and mechanisms
* Improve network troubleshooting skills
* Connect theoretical concepts with practical scenarios
